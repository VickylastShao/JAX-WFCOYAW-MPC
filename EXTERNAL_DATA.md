# External LES inputs

This public release includes compact saved trajectories, numerical accounts,
source tables, frozen protocols and research code. It does not include the
complete multi-gigabyte precursor archives, all restart flow fields or the
original GPU runtime images. Source protocols and archive manifests identify
those inputs by SHA-256 and retain historical paths as provenance, not as
public download links.

The author has authorized public sharing of the original research data. Bulk
hosting, retrieval and end-to-end checksum verification for these external
inputs remain to be completed. This is a delivery gap, not a claimed commercial
restriction. Until a public location is recorded, full LES replay is not
self-contained. Contact the corresponding author, shaozhuang@crpower.com.cn,
for coordination; this does not guarantee that every archived dependency is
immediately downloadable. No accession number or DOI is invented.

Use the available saved arrays for the supported accounting checks. The
release documentation must be updated if additional bulk data are deposited.
